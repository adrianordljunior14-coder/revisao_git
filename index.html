Atalhos do Visual Studio Code

Principais combinações para aumentar sua produtividade

Arquivos e navegação

  • Abrir arquivo / buscarCtrl + P
  • Buscar no projetoCtrl + Shift + F
  • Ir para linhaCtrl + G
  • Abrir paleta de comandosCtrl + Shift + P
  • Alternar entre arquivos abertosCtrl + Tab

Edição

  • Salvar arquivoCtrl + S
  • Salvar todosCtrl + K, S
  • Copiar linhaShift + Alt + ↑
  • Mover linhaAlt + ↑ / ↓
  • Excluir linhaCtrl + Shift + K

Seleção e comentários

  • Selecionar linha inteiraCtrl + L
  • Selecionar palavraCtrl + D
  • Comentar linhaCtrl + /
  • Comentar blocoShift + Alt + A
  • Formatar documentoShift + Alt + F

Navegação por código

  • Ir para definiçãoF12
  • Abrir referênciaShift + F12
  • Ir para símboloCtrl + Shift + O
  • Definir/abrir bookmarkCtrl + Shift + B
  • Procurar erro seguinteF8

Terminal e execução

  • Abrir terminalCtrl + `
  • Executar tarefaCtrl + Shift + B
  • Rodar arquivoCtrl + F5
  • DepurarF5
  • Parar depuraçãoShift + F5

Gerenciamento do editor

  • Novo arquivoCtrl + N
  • Novo arquivo em pastaCtrl + Alt + N
  • Fechar abaCtrl + W
  • Abrir exploradorCtrl + Shift + E
  • Toggle sidebarCtrl + B

Dica: combinar atalhos com extensões e personalizar o teclado pode acelerar muito o fluxo de trabalho.
